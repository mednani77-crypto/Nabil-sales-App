# مساعد نبيل — تطبيق مندوب المبيعات

تطبيق ويب عربي يُثبَّت على الهاتف ويعمل دون إنترنت، لمندوب مبيعات SYSCO: مخزون الشاحنة، والبيع، والتحصيل، وحساب الشركة، والإشعارات البنكية.

- المواصفات التقنية وخطة المراحل:
  [docs/SPEC.md](docs/SPEC.md)
- وصف المنتج الأصلي:
  [docs/brief-ar.md](docs/brief-ar.md)
- ملفات التصميم المعتمد:
  [design/](design/)
- تعليمات وكلاء الذكاء الاصطناعي:
  [CLAUDE.md](CLAUDE.md)

## التشغيل

```bash
npm install
npm run dev     # تشغيل محلي
npm test        # اختبارات الحسابات
npm run build   # بناء النسخة النهائية
```

## النشر

يُنشر التطبيق تلقائيًا على صفحات GitHub عند كل دمج في الفرع الرئيسي. يلزم مرة واحدة فقط تفعيل ذلك من إعدادات المستودع:
Settings → Pages → Source: GitHub Actions
