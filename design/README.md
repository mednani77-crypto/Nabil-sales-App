# Design reference

Source files of the approved design canvas (Claude Design). Each `*.dc.html` is one artboard:

- `Main.dc.html` — full interactive phone prototype (all screens + demo data + flows in its script).
- `Onboarding.dc.html` — login and opening balances wizard.
- `States.dc.html` — offline, sync, conflict, duplicate, warning, empty and loading states.
- `Desktop.dc.html` — responsive desktop layout.
- `Statement.dc.html` — A4 account statement in 5 languages.

They depend on the canvas runtime, so they are a reference for layout, copy and behaviour —
not files to run directly. The live canvas is linked from the PR that added this folder.
